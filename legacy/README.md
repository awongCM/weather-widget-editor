# Legacy implementation (2016)

This folder contains the original weather widget editor built for the Viocorp/Viostream coding assignment.

It used Gulp, Bower, jQuery, Handlebars, and Browserify. The modern replacement lives in `apps/` and `packages/`.

To run the legacy app (not recommended):

```bash
cd legacy
# Requires old Node toolchain and bower
bower install && npm install
node server.js
```
